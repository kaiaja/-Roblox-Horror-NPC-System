# Roblox Horror NPC System

An open-source, configurable horror/comedy NPC starter system for Roblox Studio.

## Features
- Wandering NPC with pathfinding and player awareness
- Branching dialogue with a proximity prompt
- Optional Roblox audio playback
- Configurable, occasional jumpscare screen effect
- R6 and R15 humanoid support (animations optional)

## Install
See [docs/INSTALLATION.md](docs/INSTALLATION.md).

## Notes
This is a starter project, not a generative-AI NPC. Test in Studio and adapt to your game. Audio assets must be owned by or permitted for your experience.
